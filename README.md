# JobTrack
A user can manage all their job applications in one place, track their progress, and monitor upcoming interviews.

## Features (MVP)

**1. Add Application** – Add a company, job title, application date and job URL.<br>
**2. View Applications** – See all your job applications.<br>
**3. Update Application** – Change application status (Applied, Interview, Rejected, Offered).<br>
**4. Delete Application** – Remove an application.
